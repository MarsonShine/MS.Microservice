# 敏感字段的输出边界

字段分类描述属性用途，适配器决定何时处理。Phone／Email 产生掩码，Secret 不提供值；EF 审计可另外保留字段发生变化的事实。标记不会加密数据库，也不会使普通 ILogger、Excel 或所有序列化调用自动变得安全。

标量规则只处理字符串，Phone 限制普通数字表示与可选前导加号，保留首三字符和末四字符，中间保持长度以星号代替。Email 保留首个 Unicode 标量和 ASCII 域名；不符合支持形式的输入整体替换为 `[REDACTED]`。这不是国际电话或 RFC 邮箱验证器，也不对低熵数据提供匿名化保证。空字符串与 null 保持空；Secret 始终不返回值。

扁平投影按实际类型缓存字段计划，复用已有 PropertyAccessors 的编译读取委托。元数据解析只发生在类型首次使用时。普通标量保留，导航／嵌套对象省略；已标记的 Phone／Email 必须是字符串。Secret 字段连 getter 都不读取，避免在遮盖之前产生额外敏感副本。返回新字典，不修改原对象。未标记字段不具备自动个人信息识别能力。

LogSensitive 在日志级别关闭时直接返回，启用时先创建受保护投影，再将结构化状态交给 ILogger。状态和 formatter 仅引用受保护字典，不持有业务 DTO 或被删除的秘密值；NLog、Serilog、异步队列收到的已是处理结果。eventName 必须来自可信、固定的业务事件名，不应将用户数据拼进事件名。已有普通日志和异常文本不由这个入口重新扫描。

JSON 适配器在现有 System.Text.Json 类型解析器上添加 modifier，保留命名策略和 setter。输出时对标记的 getter 结果处理；Secret 的输出 getter 改为空并禁止写出，读入仍由原 setter 接收。属性声明与运行时反射元数据负责分类，自定义 converter 或未启用的 JSON 配置不在此处理边界中。需要裁剪／AOT 时必须先提供可验证的显式元数据契约，不能将反射投影宣传为零反射实现。

掩码后旧值与新值可能相同，因此审计应先用原值判断变化，再遮盖写出的快照，并标明保护方式。保护不改变 EF 跟踪快照，也不改变业务值；数据库加密、完整值访问授权、密钥来源和轮换仍由宿主管理。调用方如需展示完整内容，应使用单独授权的 DTO 和输出入口，不能通过请求参数任意关闭保护。

首次投影还包含类型计划和访问器编译，热路径结果不能代替冷启动耗时。[性能记录](../../../docs/components/cache-sensitive-performance.md)区分首次投影、掩码、投影、等价 JSON 输出、日志状态和 SQL 前审计采集，且不包含存储或日志后端 I/O。
