# 本地流保存

`LocalFileStorage` 接受宿主选择的可信目录，将输入流当前位置至末尾的内容保存为随机文件名，并返回文件名。目录在构造时解析为绝对路径；调用方流始终由调用方释放。

扩展名须为一个点加 1–9 个 ASCII 字母或数字，输出统一小写。该检查只控制文件名，不识别媒体格式；HTTP 上传的类型、大小和文件头校验由 AspNetCore 组件与宿主策略负责。

保存先写同目录下本次新建的临时文件，关闭后通过不覆盖目标的移动发布。复制失败或取消时清理该临时文件，不删除其他文件。操作期间宿主需保证目录可信且稳定；这不是面向恶意本机进程的文件系统隔离。进程被强制终止或机器断电后可能有未清理的临时文件，保留期清理由宿主负责。发布后发生取消不撤销已经完成的文件。

Lab 的 `LocalUploadStorage` 保留内容根目录约束和配置接入，调用此组件保存；应用的文件记录、权限、下载和对象存储不属于该类。
