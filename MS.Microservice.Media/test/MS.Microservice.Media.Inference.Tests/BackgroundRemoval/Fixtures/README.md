# 人像测试来源

`grace-hopper.jpg` 从本机 Matplotlib 的 sample_data 原样复制，摄影者 James S. Davis，1984 年美国海军官方肖像，编号 NH 96919-KN。Matplotlib 的[原始引入提交](https://github.com/matplotlib/matplotlib/commit/5da2608950866c9e821177b20b6cfadfd76d3b7a)记录其美国联邦政府公务作品与公有领域来源。

该图片只用于真实模型与像素合同验证，不是作者提供的 alpha 真值。测试不据此承诺人像、发丝或复杂背景质量；不包含私人人像或模型权重。
